# Quantum Tools UI — design tokens

Graphite/near-black surfaces are structural. Cyan is the primary technical accent. Amber is reserved for interactive/attention states. Green and red are semantic success/error states, not decoration. Text hierarchy uses bright off-white for primary data and desaturated blue-grey for labels.

The UI kit must remain readable as Minecraft pixel UI: clipped corners and technical lines are allowed, but micro-decoration may not reduce slot, text or state readability. Shared components are preferred over one-off screen styling.
