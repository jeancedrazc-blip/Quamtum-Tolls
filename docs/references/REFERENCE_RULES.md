# Reference acceptance rules

1. Constructor geometry must match `constructor-ct01-approved-reference.webp`: raised pivot, real turret base, long elevated barrel, no floor-level barrel.
2. Schematic Table geometry must match `schematic-table-approved-reference.webp`: recognizably a table/workbench, not a generic cube.
3. Miner must match `miner-approved-reference.webp`: Concept 01 revised, near-flush front and orange detail accents.
4. UI must follow `ui-visual-language-reference.webp`: dark industrial frame, cyan hierarchy, restrained orange, aligned spacing and readable Minecraft-scale text.
5. Cards must follow `cards-visual-language-reference.webp`, but the final approved 32x32 card texture family remains authoritative over earlier card-board proportions.
6. Any screenshot that visibly conflicts with an approved reference blocks release promotion.
7. GitHub Actions validates compilation/API compatibility only. Runtime behavior and visual acceptance require in-game testing.
